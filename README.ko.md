## About

해당 프로젝트는 깃허브의 README 컴포넌트를 모아 보다 쉽고 예쁘게 **README.md**를 만들고 싶다는 생각에서 출발하였습니다.

***수많은 svg, badge, component들을 찾기 힘들지 않으셨나요?*** readme-cavas를 사용하시면 한 번에 원하는 컴포넌트를 탐색하고 찾을 수 있습니다. 다양한 꾸미기 도구들을 활용하여 나만의 readme를 빠르게, 그리고 아주 예쁘게 만들 수 있어요. ✨

## Login

해당 프로젝트는 따로 로그인이 필요 없습니다. 하지만 로그인을 하시면 더 편하게 서비스를 즐길 수 있습니다.

**Connect GitHub 버튼 클릭 → 발급받은 Github Token 입력**

reademe-canvas에서 만든 markdown 파일을 원하는 프로젝트에 바로 push 할 수 있습니다. 또한 component 추가가 가능해집니다. (* 계정 정보는 서버에 저장되지 않습니다.)

## Contributing

해당 프로젝트는 기여자를 환영합니다.

예상하는 기여 부분은 아래와 같습니다.

1. 프로젝트 개선 기여자

1. 컴포넌트 개발자

1. 번역 기여자

가장 중요하게 여기는 부분은 2번 컴포넌트 개발자입니다. 해당 사이트가 깃허브 컴포넌트를 홍보할 수 있는 하나의 수단으로 자리잡길 바랍니다.

## component 추가하는 방법 (PR)

해당 서비스의 ‘**컴포넌트 추가하기**’ ui를 통해 쉽게 추가할 수 있습니다. 깃허브 토큰을 통해 로그인하고, 컴포넌트 추가 버튼을 누를 시 **자동으로 pull request**가 날라가는 구조입니다.

외에 직접 .json 파일을 추가하여 직접 pull request를 날려주실 수 있습니다.

커뮤니티 컴포넌트는 `src/data/community-components/` 아래에 파일 하나당 하나씩 들어 있습니다.

1. 저장소를 포크합니다.

1. `**src/data/community-components/<tag>.<프로젝트개발자id>.<projectname>.json**` 파일을 새로 추가합니다

(id는 소문자, 하이픈으로 구분 — 예: `social-mastodon.json`).

아래에 자세한 방법이 적힌 파일을 첨부하오니, 관심이 있다면 확인해주시면 감사하겠습니다.
