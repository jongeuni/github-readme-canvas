## About

This project started with a simple idea: **make it easier to create beautiful GitHub README.md files by bringing README components together in one place.**

Have you ever had trouble finding the right SVGs, badges, or other README components? With **readme-canvas**, you can explore and find the components you need in one place.

Use a variety of styling tools to create your own README quickly — and make it look great while you're at it. ✨

## Login

You don't need to create an account or log in to use readme-canvas.

However, connecting your GitHub account gives you access to additional features and makes the workflow more convenient.

Your GitHub token is **not stored on our server**.

**Click `Connect GitHub` → Enter your GitHub Token**

Once connected, you can push the Markdown files created with readme-canvas directly to your desired GitHub repository. You can also add your own components to the service.

## Adding a Component via PR

You can easily submit a component through the **Add Component** UI.

After connecting your GitHub account with a GitHub token, clicking the **Add Component** button will automatically create a pull request for you.

Alternatively, you can manually add a `.json` file and open a pull request yourself.

Community components are stored under:

`src/data/community-components/`

Each component has its own JSON file. This means that when you open a PR, you only need to modify your own file, so your changes should not conflict with other contributors' PRs.

## How to Contribute

1. Fork this repository.

1. Add a new file at ***src/data/community-components/<tag>.<your-id>.<project-name>.json.***

Use lowercase letters for your ID and separate words with hyphens.

Example: ***social-mastodon.json***

3. Follow the detailed instructions in the guide below.

We have attached a detailed guide explaining how to create and submit a component. If you're interested in contributing, we'd really appreciate it if you could take a look!
